⛔⛔ Google's hand-landmarker page licenses **code samples** (Apache 2.0) and

⭐ Almost certainly fine — but **this row's whole point is that *almost certainly*
is not the standard.** It does not block the platform decision (same model on
every candidate), and it **must** be settled in writing before a store
submission. Folds into the licence inventory `SEC2` already records as owed.

⚠ And it now covers the RUNTIME's binding too: a React Native / Flutter MediaPipe
plugin would be a **third-party** dependency needing its own clearance, whereas
first-party Android / iOS / Web SDKs inherit the Apache 2.0 above.
