## Appended 2026-08-25 — ⭐⭐ THE MODEL CARD CORROBORATES THE WORLD-Z DIAGNOSIS

This project measured, over months, that **MediaPipe's world z is fabricated** —
the k-sweep, the roll control, four A10-rejected estimator replacements. The
Model Card says it outright:

> *"Landmark screen z-value and 3D metric x, y, z coordinate values estimate is
> provided using **synthetic data**, obtained via the GHUM model (articulated 3D
> human shape model) fitted to 2D point projections."*

⭐⭐ **And Google does not evaluate z at all**, for the same reason:

> *"The model provides 3D coordinates, but as the z screen coordinates as well as
> metric world coordinates are obtained from synthetic data, so for a fair
> comparison with human annotations, **only 2D screen coordinates are
> employed**."*

⚠ **So the depth channel the yaw lean depends on has never been accuracy-tested
by its authors.** That is the strongest external support the diagnosis has, and
it closes the question of whether the tilt is our fit or the sensor: it is the
sensor, by construction.

⭐ Also corroborating a shipped choice: the card normalises by **palm size =
wrist to middle-finger MCP (0→9)** — the same span `palm_depth` uses.
